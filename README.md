# CyberSafe Chatbot

CyberSafe Chatbot is a beginner-friendly web application designed to teach users basic cybersecurity concepts and help identify suspicious messages.

## Features
- Interactive chatbot interface
- Educational responses about phishing, malware, 2FA, and password safety
- Suspicious message analysis
- Phishing risk score
- User-friendly and responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser
